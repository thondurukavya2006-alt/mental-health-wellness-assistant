# Mental Health Risk Detection and Intelligent Wellness Assistant

## Project Overview
An AI-based wellness platform designed to analyze emotional patterns, lifestyle habits, and academic stress to help users understand their stress and anxiety risk levels.

## Key Features
- Mood and sleep pattern analysis
- Text-based sentiment analysis
- Academic stress monitoring
- Stress and anxiety risk assessment
- Personalized wellness recommendations
- Mental wellness history and progress tracking

## Live Website
https://tasteful-mind-sync-flow.base44.app

## Domain
Artificial Intelligence (AI) and Machine Learning (ML)

## Purpose
To promote mental wellness awareness through intelligent analysis and personalized recommendations. This tool is for wellness support and is not a medical diagnostic system.
